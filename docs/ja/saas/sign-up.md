# サインアップ

SaaS オンボーディングフローのステップ 1：Geolonia へのお問い合わせを送信します。

::: tip 招待制アクセス
GeonicDB SaaS にはセルフサービスのサインアップページが**ありません**。アクセスは管理されたオンボーディングプロセスを通じて付与されます。
:::

## アクセス申請方法

1. [https://www.geolonia.com/contact/](https://www.geolonia.com/contact/) にアクセス
2. お問い合わせフォームに以下を記入：
   - **会社・組織名**
   - **ユースケース** — 構築したいものを説明（例：IoT センサー管理、スマートシティデータプラットフォーム、FIWARE 移行）
   - **推定データ量** — エンティティ数、更新頻度
   - **希望リージョン** — 日本（ap-northeast-1）またはその他
3. フォームを送信 — Geolonia から **1〜2 営業日** 以内に返信いたします

送信後、Geolonia が申請を確認し、承認とテナントのプロビジョニングについてご連絡します。

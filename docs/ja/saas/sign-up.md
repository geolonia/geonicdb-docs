# サインアップ

GeonicDB SaaS は **招待制** で提供されています。セルフサービスでのサインアップには対応していません。アクセスは Geolonia チームとの管理されたオンボーディングプロセスを通じて付与されます。

## アクセスの申請方法

1. [https://www.geolonia.com/contact/](https://www.geolonia.com/contact/) にアクセス
2. 問い合わせフォームに以下の情報を記入：
   - **会社名 / 組織名**
   - **ユースケース** — 構築したいもの（例：IoT センサー管理、スマートシティデータ基盤、FIWARE 移行など）
   - **想定データ量** — エンティティ数、更新頻度
   - **希望リージョン** — 日本（ap-northeast-1）またはその他
3. フォームを送信 — Geolonia から **1〜2 営業日以内** にご返信いたします

## 申請後の流れ

申請内容を確認後、Geolonia は以下の手順で対応します：

1. **ユースケースの評価** — GeonicDB SaaS がご要件に適しているか確認
2. **テナントのプロビジョニング** — ご希望の名前で独立したテナントを作成
3. **招待メールの送信** — アカウント有効化の手順と初期 API キーをお届け
4. **オンボーディング通話の設定**（任意）— 一緒にセットアップを進めます

## アクセス内容

各アカウントには以下が含まれます：

| 項目 | 詳細 |
|------|------|
| テナント | 専用テナント 1 つ（追加テナントはご相談ください） |
| API アクセス | NGSIv2 および NGSI-LD API へのフルアクセス |
| コンソールアクセス | `app.geonicdb.com`（Coming Soon — 現在はオンボーディング時に対応） |
| サポート | Geolonia アカウント担当者によるメールサポート |

## よくある質問

**無料トライアルはありますか？**
トライアルオプションについては Geolonia にお問い合わせください。ケースバイケースで対応いたします。

**チームメンバーを追加できますか？**
はい。アカウントが有効化された後、アカウント担当者に連絡することで追加ユーザーを登録できます。

**対応しているリージョンはどこですか？**
GeonicDB SaaS は現在、日本（AWS ap-northeast-1）でホストされています。他のリージョンはロードマップに含まれています。

**セルフホストでの利用は可能ですか？**
GeonicDB のセルフホストオプションは現在一般提供されていません。デプロイ要件についてはお問い合わせください。

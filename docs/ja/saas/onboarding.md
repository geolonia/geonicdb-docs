# オンボーディング

お問い合わせを受領した後、Geolonia はユースケースを審査して GeonicDB SaaS アカウントをプロビジョニングします。このページでは、オンボーディングフローのステップ 2・3（Geolonia からの連絡とアカウント情報の提供）について説明します。

::: tip SaaS オンボーディングフローのステップ 2・3
1. ~~[Contact Sales（お問い合わせ）](/ja/saas/sign-up)~~ — 完了
2. **Geolonia からの連絡** — 審査と承認 ← *現在のステップ*
3. **アカウント情報の提供** — テナント名と管理者認証情報 ← *現在のステップ*
4. [テナント管理ユーザーの作成](/ja/saas/tenant-admin-user) — CLI を使用
5. [API キーの作成](/ja/saas/api-key) — CLI を使用
6. [最初の API 呼び出し](/ja/saas/first-call) — 設定を確認
:::

## ステップ 2: Geolonia からの連絡

お問い合わせを受領してから通常 **1〜2 営業日** 以内に、Geolonia は以下の対応を行います：

- **ユースケースの確認** — GeonicDB SaaS がご要件に合っているかを確認
- **テナントのプロビジョニング** — お客様専用のテナントを作成
- **ご連絡** — メールまたは電話でアカウント設定の調整

申請が承認された場合は、アカウント情報の提供（ステップ 3）に進みます。追加情報が必要な場合は、Geolonia から確認の連絡をいたします。

## ステップ 3: アカウント情報の提供

テナントのプロビジョニングが完了すると、Geolonia から以下の情報がセキュアな方法で送付されます：

| 項目 | 説明 |
|------|------|
| **Admin エンドポイント URL** | テナント向け GeonicDB Admin API の URL |
| **管理者ユーザー名** | 初期スーパー管理者またはテナント管理者アカウント |
| **管理者パスワード** | 一時パスワード — 初回ログイン後に変更してください |
| **テナント名** | テナントの識別子（例：`my-company`） |

::: warning 認証情報の管理
受け取った認証情報はすぐにパスワードマネージャーまたはシークレット保管庫に保存してください。管理者パスワードは一時的なものとして扱い、初回 CLI ログイン後に必ず変更してください。
:::
